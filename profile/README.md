## 👋 Добро пожаловать

**PushPilot** — сервис push-уведомлений для разработчиков и команд. Настраивайте проекты, подключайте свои credentials и отправляйте уведомления через единый REST API.

Мобильные приложения и браузеры, обычные и фоновые уведомления, PushKit / VoIP для iOS — в одной системе.

## ⚡ Что внутри

- **Единый API** для отправки уведомлений и получения статусов.
- **APNs, FCM и Web Push** для iOS, Android и браузеров.
- **Свои credentials** — подключайте учётные данные ваших приложений.
- **Проекты и окружения** — разделяйте клиентов, приложения и доступ.
- **API-ключи с правами** — выдавайте доступ к нужным операциям.
- **История и аналитика** — отслеживайте отправки, ошибки и использование тарифа.

<a name="quickstart"></a>

## 🚀 Быстрый старт

1. Создайте аккаунт на [PushPilot](https://pushpilot.ru/register).
2. Добавьте проект и приложение в клиентском кабинете.
3. Настройте APNs, FCM или VAPID credentials для Web Push.
4. Подключите [SDK вашей платформы](https://github.com/pushplatform/pushpilot-sdks/sdks) и регистрацию устройств.
5. Создайте API-ключ с нужными правами для серверной интеграции.
6. Отправляйте уведомления через REST API и смотрите статусы.

## ❤️ Разработчикам

Мы делаем PushPilot для тех, кто хочет управлять push-интеграцией через свои проекты, credentials и API-ключи.

- [Следите за проектом на GitHub](https://github.com/pushplatform).
- Об ошибках и предложениях пишите в **Issues** соответствующего SDK.
- При сообщении об ошибке укажите платформу, версию SDK и шаги воспроизведения. Удалите из логов API-ключи, токены устройств и credentials.
